# ai-usage-macos-widget — лимиты AI-подписок в Центре уведомлений macOS

Нативное приложение macOS (SwiftUI + WidgetKit): виджет в Центре уведомлений и
строка меню, показывающие расход подписочных лимитов AI-провайдеров
(OpenAI/Codex, Z.ai GLM, Kimi Code, баланс OpenRouter) — как карточка LIMITS
в DSH-плагине `@linxin666/dsh-usage`, но независимо от харнесса: видно и в Kilo,
и в DSH, и в любом другом клиенте с теми же аккаунтами.

## Ключевые решения

- **Публикация**: открытый GitHub `SerzhSharapa/ai-usage-macos-widget`
  (решение владельца 11.10.2026). README — трёхъязычный, лицензия MIT.
- **Данные берутся у провайдеров напрямую**, теми же эндпоинтами, что и в
  `@linxin666/dsh-usage` (референс — установленный пакет, см. ниже), а не
  из состояния DSH или Kilo.
- **Секреты — только в Keychain** macOS. Ключи не попадают в git, логи,
  пользовательские дефолты и сам виджет.
- **Виджет обновляется по бюджету WidgetKit** (~15–60 мин); частая проверка —
  в строке меню и по ручному обновлению. Гарантировать поминутную свежесть
  в виджете нельзя — это ограничение платформы, не баг.

## Референсы

- `~/.dsh/profiles/gsd-local/node_modules/@linxin666/dsh-usage/src/core/adapters.ts`
  — эндпоинты и парсеры ответов провайдеров (OpenAI wham/usage, Kimi coding usages,
  Z.ai/bigmodel plan, OpenRouter credits). Транспортом не делиться: адаптеры там
  чистые, повторяем свою реализацию на Swift.
- README самого плагина — состав окон и провайдеров.
