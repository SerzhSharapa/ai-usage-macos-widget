## Critical Anti-Patterns

| Pattern | Severity | Prevention |
|---------|----------|------------|
| Считать shell self-tests доказательством работающей личной подписи | blocking | 01-04 проверяет подписанные продукты и установленный виджет вне отладчика; до этого только кодовые проверки PASS |
| Создать completion SUMMARY во время ожидания обязательного checkpoint | blocking | 01-04 не имеет SUMMARY; 01-05 использует отдельный WAITING.json, итоговый SUMMARY только после фактического истечения и пересборки |
| Доверять argv, bundle ID или metadata executable без проверки границ | blocking | stop-wrapper проверяет целостность бандла и canonical boundary; native helper проверяет kernel executable и birth identity; symlink-побеги отклоняются до сигналов |
