## Что это

Небольшое нативное приложение macOS (SwiftUI + WidgetKit), которое показывает
расход подписочных лимитов AI-провайдеров — виджетом в Центре уведомлений и
пунктом в строке меню, в стиле карточки LIMITS плагина DSH
`@linxin666/dsh-usage`.

В отличие от плагина харнесса, оно независимо от кодинг-клиента: данные
запрашиваются у провайдеров напрямую, и те же цифры видны и в Kilo, и в DSH,
и в любом другом инструменте с теми же аккаунтами.

Планируемые провайдеры (проверено по референс-плагину, 11.10.2026):

| Провайдер | Что показывается |
|---|---|
| OpenAI (Codex / ChatGPT) | окна расхода плана |
| Z.ai (GLM Coding Plan) | окна 5h и недельное |
| Kimi Code | окна 5h и месячное |
| OpenRouter | баланс pay-as-you-go |

## Как это работает

```
┌────────────────────────┐        ┌─────────────────────────────┐
│  Приложение-компаньон  │        │  Провайдеры (HTTPS)         │
│  • вид в строке меню   │◄──────►│  OpenAI · Z.ai · Kimi · OR  │
│  • запрос + кэш        │        └─────────────────────────────┘
│  • ключи в Keychain    │
└──────────┬─────────────┘
           │ таймлайн WidgetKit
           ▼
┌────────────────────────┐
│  Виджет в Центре       │
│  уведомлений (SwiftUI) │
└────────────────────────┘
```

- API-ключи хранятся в **Keychain** macOS — не в git, логах и не в самом виджете.
- Виджет обновляется по системному бюджету WidgetKit (примерно раз в 15–60 минут);
  в строке меню доступно обновление по требованию.
